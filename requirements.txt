# ----------------------------------------------------------------
#    - Unduh dari: https://git-scm.com/downloads

# 3. GOOGLE CHROME
# ----------------------------------------------------------------
#    - Unduh dari: https://www.google.com/chrome/

# ----------------------------------------------------------------
#    - Ini diperlukan untuk menjalankan antarmuka web (PHP) dan

#    - XAMPP: https://www.apachefriends.org/
#    - Laragon: https://laragon.org/
#
# ================================================================
# LANGKAH 1: SETUP PROYEK
# ================================================================
#
# 1. Buka Terminal (Command Prompt / Git Bash).
#
# 2. (Opsional) Jika belum, clone repositori proyek:
#    git clone [URL_REPOSITORI_ANDA] dapokalsel
#
# 3. Masuk ke direktori proyek Anda.
#    (Pilih salah satu sesuai server lokal Anda)
#
#    # Untuk pengguna Laragon:
#    cd C:/laragon/www/dapokalsel
#
#    # Untuk pengguna XAMPP:
#    cd C:/xampp/htdocs/dapokalsel
#
# ================================================================
# LANGKAH 2: BUAT & AKTIFKAN VIRTUAL ENVIRONMENT
# ================================================================
#
# Ini akan membuat folder 'venv' di dalam proyek Anda
# untuk mengisolasi library Python.
#
# 1. Buat virtual environment:
#    python -m venv venv
#
# 2. Aktifkan virtual environment:
#    .\venv\Scripts\activate
#
#    (Jika berhasil, Anda akan melihat (venv) di awal baris terminal Anda)
#
# ================================================================
# LANGKAH 3: INSTAL SEMUA LIBRARY PYTHON
# ================================================================
#
# 1. Pastikan Anda masih berada di dalam virtual environment (venv).
#
# 2. Jalankan perintah berikut untuk menginstal semua package
#    yang terdaftar di bawah ini:
#
#    pip install -r requirements.txt
#
